# Expo notes for this project

This app is on **Expo SDK 58** (expo-router v58, React Native 0.88), built with
Xcode 27 against the iOS 27 SDK (scene-based life cycle, generated by prebuild).
Consult the versioned docs at https://docs.expo.dev/versions/v58.0.0/ before
writing code. The app ships native code (`modules/dual-camera`, purchases, maps),
so test on TestFlight / development builds, not Expo Go.

- Imports: `Tabs`/`Stack`/`Redirect` from `expo-router`; nav theming
  (`ThemeProvider`, `DefaultTheme`, `DarkTheme`) from `expo-router/react-navigation`
  (expo-router no longer depends on `@react-navigation/*`).
- Native iOS minimum is 16.4 (keep `modules/dual-camera` podspec in step).
- `npm install` requires the checked-in `.npmrc` (legacy-peer-deps).
- Typecheck with `npm run typecheck`; web build with `npm run export:web`.
